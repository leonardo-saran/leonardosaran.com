# leonardosaran.com

My personal blog and living portfolio: documenting my journey through
my Software Engineering postgraduate program, projects, and career
transition into tech.

**[Read it here](https://leonardosaran.com)**

## About this repository

Built on top of [blog-template](https://github.com/leonardo-saran/blog-template),
a minimal, bilingual, zero-dependency static blog (vanilla HTML/CSS/JS,
Markdown content, GitHub Pages). See the upstream repository for the full
feature list and customization guide.

My changes live in:

- `src/content/`: posts, projects, and the About page
- `src/content/settings.txt`: site configuration
